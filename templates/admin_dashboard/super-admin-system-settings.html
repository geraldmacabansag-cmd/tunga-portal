Email Provider (for OTP & system emails)

What is this?

  • The website sends some emails by itself. For example, the 6-digit code people receive when they sign up or forget their password.
  • This box tells the website which email address those emails come from.
  • The emails are sent through a free service called Brevo. It can send up to 300 emails a day for free.
  • Sending from now: {% if email_settings.has_saved_brevo %}{{ email_settings.email_address }} {% elif email_settings.using_default_brevo %}{{ email_settings.default_brevo_email }} (the account set up when the website was installed) {% else %}no email yet, so codes are not being sent{% endif %}
  • The Brevo API Key is like a password. After you save it, it is hidden and locked. Nobody can see it again, not even you.
  • If Brevo cannot send for a while (for example, too many emails in one day), the Backup Email Sender below sends them instead.

How to change the email that sends the codes

  1. Go to brevo.com and log in with the LGU's account, or make a new free account.
  2. Add the LGU email address that the codes should come from. Brevo sends a message to that email. Open it and click the link to confirm.
  3. In Brevo, click the menu at the top right, then SMTP & API, then API Keys, then Generate a new API key. Copy the long code it shows.
  4. Come back to this page. Type the LGU email in Sender Email and paste the long code in Brevo API Key. Click Save Email Provider.
  5. Click Send test email. Open the email inbox and check that the test email arrived.
  6. In the old Brevo account, delete the old key so it can no longer be used.

The button Use the default account goes back to the email that was set up when the website was installed. If you get stuck, ask the person who set up the website. Using an email service other than Brevo, Mailjet or Gmail needs changes by a programmer.

This is used to send one-time codes (for forgot password) and other system emails, via Brevo's email API. The API key is encrypted before it's stored — it's never shown back to you after saving, only whether one is currently on file.

Backup Email Sender

What is this?

  • A second email account, used only when Brevo cannot send. This way people still receive their codes.
  • Now: {% if email_settings.backup_ready %}ready, sending from {{ email_settings.backup_email }} {% elif email_settings.backup_provider %}not ready yet, a code or password is missing {% else %}no backup is set up{% endif %}
  • There are two choices:
    Mailjet (recommended): free, up to 200 emails a day.
    Gmail: about 500 emails a day, but it does not work with some website hosting. Always send a test email.

How to set up or change the backup

With Mailjet

  1. Go to mailjet.com and make a free account. Add the LGU email and confirm it from the message Mailjet sends.
  2. In Mailjet open Account, then API Keys. Copy the two codes: the API Key and the Secret Key.
  3. On this page choose Mailjet in Backup service, type the email and paste both codes. Click Save Backup Sender.
  4. Click Send test email through backup and check the inbox.

With Gmail

  1. In the Google account, turn on 2-Step Verification. Then search for App passwords and make one. Google shows 16 letters. Copy them.
  2. On this page choose Gmail, type the Gmail address and paste the 16 letters. Click Save Backup Sender.
  3. Click Send test email through backup and check the inbox.

To turn the backup off, choose No backup and click Save Backup Sender.

If Brevo can't send an email (for example its 300 emails a day free limit is used up, or Brevo is down), the website automatically sends the same email through this backup. Codes for sign-up and password reset, and status updates of online forms, still reach people.
