How it works

Automatic backups start by themselves when a Super Admin opens the dashboard and the last one is more than 24 hours old. On DigitalOcean, also add a daily job: python manage.py backup_site --auto

Restoring replaces all website data with the backup's. A safety backup of the current site is made first, and if anything goes wrong nothing is changed. Files already in storage are never deleted.

Keep a copy elsewhere: download a backup now and then to an office computer or USB drive. Backups contain user accounts, so keep the files private.
